# Если что-то не запускается

| Симптом | Что сделать |
|---|---|
| `brew` не найден | Установить Homebrew с brew.sh, открыть новый Terminal, повторить `./start.sh` |
| Не удаётся скачать модели | Проверить доступ к GitHub/Hugging Face. Скачайте разрешённым способом и выберите файлы в настройках. Для запуска без скачивания: `SAMARIZATOR_SKIP_DOWNLOAD=1 ./start.sh` |
| Ошибка `whisper-cli` | Проверить `whisper-cli --help`, путь к GGML `.bin`, права чтения файла и язык. Установщик использует `brew install whisper-cpp` |
| Установил `large-v3`, но текст не изменился | Проверьте выбранный `.bin` в настройках и нажмите **«⋯» → «Распознать заново»**. «Распознать» использует модель, сохранённую для старой записи |
| `large-v3` работает слишком медленно | Сравните с `large-v3-turbo` или `large-v3-q5_0` по [руководству по моделям](models.md). Уменьшение модели меняет компромисс скорости и качества |
| Сработала защита памяти | Выбрать меньшую модель или увеличить бюджет с запасом для macOS; нажать «Распознать» |
| macOS не открывает приложение («не удаётся проверить разработчика») | Сборка без платной подписи Apple. macOS 15+: Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть». macOS 13–14: правый клик по приложению → «Открыть». Один раз |
| «Локальная модель сводок не найдена» | Нажать «Скачать модель сводок» внизу списка записей или выбрать файл `.gguf`: Настройки → Основное → «Сводки» → «Сменить…» |
| Не скачивается модель сводок | Нужен доступ к huggingface.co. Повторите — загрузка продолжится с места остановки. Или скачайте `.gguf` другим разрешённым способом и выберите его: «Сменить…» → «Выбрать файл .gguf…» |
| «Модели сводок нужно около N ГБ памяти» | Выбрать модель меньше или уменьшить «Символов текста на запрос» (Настройки → Для опытных → Сводка) |
| «Модели не хватило памяти» / сводка остановилась у границы бюджета | Закрыть тяжёлые приложения, выбрать модель меньше или уменьшить размер блока |
| Сводка идёт очень долго | Проверить, что включено «Ускорение сводок на GPU» (Настройки → Основное). Строка состояния показывает «осталось ≈ N мин», в конце — скорость модели и время этапов. Быстрее всего GigaChat 3.1 Lightning; модели 26B–30B «смесь экспертов» быстрее обычных 12B |
| Сводка короче обычного, баннер «Чтобы уложиться в N мин» | Сводка не успевала за «Время на сводку» и пропустила проверку части блоков или написала конспект короче. Поставьте больше времени или «без ограничения» (Настройки → Основное → Сводка) и «⋯» → «Сделать сводку заново…» |
| Итоговый текст «может быть неполным» | Выбрать более краткий формат или увеличить «Лимит токенов ответа» (Настройки → Для опытных → Сводка), затем «⋯» → «Пересоздать итоговый текст» |
| Итоговый текст не в том формате | Выбрать формат прямо над итоговым текстом или переписать шаблон: Настройки → «Шаблон итогового текста», затем «⋯» → «Пересоздать итоговый текст» — запись заново не разбирается |
| Проверить, всё ли на месте в приложении | `/Applications/Samarizator.app/Contents/MacOS/Samarizator --run-module samarizator.selfcheck` в Terminal |
| В расшифровке фразы, которых не было: «Субтитры создавал…», «Редактор субтитров… Корректор…», «Продолжение следует» | Известные выдумки Whisper на тишине и шуме, часто на стыке фрагментов. Над расшифровкой нажмите «Удалить все…» и подтвердите. Если их много, проверьте, что включено «Выделять речь (VAD)» (Настройки → Для опытных), и распознайте заново моделью Podlodka Turbo |
| «Исходный файл перемещён» — распознавание не продолжается, «Создать сводку» нет | Файл записи пропал до конца распознавания: его перенесли или удалили, либо запись старой версии с live-записью оборвалась. В красном баннере: **«Указать файл…»** — если файл есть в другом месте (приложение сверит, что это та же запись, и продолжит), или **«Сводка по готовой части»** — расшифровка завершится на уже распознанном тексте, и по нему можно будет создать сводку |
| Изменился исходный файл | Вернуть исходный файл или импортировать изменённый как новую запись. Контрольная сумма намеренно блокирует смешивание версий |
| Obsidian не открывает заметку | Приложение берёт список хранилищ из конфига Obsidian и обращается к нужному по его идентификатору, поэтому имя папки и символические ссылки iCloud больше не мешают. Если ни одно зарегистрированное хранилище не содержит заметку, кнопка показывает, какие хранилища Obsidian знает, и предлагает открыть папку в Finder. Лечится так: Obsidian → «Открыть папку как хранилище» → выбрать папку из настроек. Просто существующей на диске папки недостаточно |
| Приложение прервано | Запустить снова: статус станет «Приостановлена». Нажать продолжение нужной стадии |

## Шумная запись: обработка перед распознаванием

Обработку можно включить на своей стороне — **только для того, что слышит Whisper**. Файл на
диске не меняется, профиль можно переключить и распознать заново.

На синтетическом образце (речь отрывками, шипение и гул 50 Гц) разница между уровнем речи
и уровнем пауз получилась такой: без обработки 7.9 дБ, `light` — 14.6 дБ, `strong` — 18.7 дБ.
На вашей записи числа будут другими.

| Профиль | Что делает | Когда брать |
|---|---|---|
| `off` | ничего | по умолчанию; звук и так чистый |
| `light` | срез гула ниже 80 Гц и выравнивание громкости речи | обычный кабинет, тихий микрофон |
| `strong` | то же плюс подавление широкополосного шипения | шумная комната; может смазывать тихую речь |

Выбирается в **Настройки → Для опытных → «Качество распознавания» → «Обработка звука перед распознаванием»**.

## Проверка установки

```bash
whisper-cli --help
ffmpeg -version
uv run --frozen python -c 'from samarizator.config import data_dir; print(data_dir())'
```

## Без интернета после установки

Готовое приложение работает офлайн целиком: распознавание и сводки выполняются на Mac.
Интернет нужен один раз — скачать модель сводок (или выберите заранее скачанный `.gguf`).

При запуске из исходников модели и пакеты должны быть установлены заранее; запуск из
окружения не обращается к менеджеру пакетов:

```bash
.venv/bin/python -m samarizator.app
```
