# Качество распознавания

Как приложение добивается точной расшифровки, где оно честно помечает сомнения и как
перепроверить спорные места. Выбор модели Whisper — в [руководстве по моделям](models.md).

## Профиль качества

**Настройки → Для опытных → «Применить профиль M4 Pro · 48 ГБ»** (из исходников —
`./start.sh --quality`): бюджет памяти 16 ГиБ, 8 потоков, фрагменты около 90 секунд,
поиск ближайшей паузы на границах, VAD и beam size 5. Выбранные модели распознавания и
сводок профиль не меняет. Для новой модели или профиля у существующей записи нажмите
**«⋯» → «Распознать заново»**: создаётся новая запись, прежний текст и ручные правки
сохраняются. Продолжение старой расшифровки намеренно использует её прежние параметры.

## Как устроено распознавание

- **Фрагменты.** Запись не загружается целиком: FFmpeg и Whisper обрабатывают её фрагментами
  (по умолчанию 120 секунд, в профиле качества — 90). Соседние фрагменты перекрываются на
  2 секунды. План границ сохраняется в SQLite и переиспользуется при продолжении; каждая
  порция текста фиксируется вместе с контрольной точкой, поэтому продолжение не дублирует текст.
- **Границы по паузам.** С включённым поиском пауз граница сдвигается к тишине в пределах
  ±6 секунд. Аудио при этом не обрезается. Нет паузы — остаётся временная граница с пометкой
  для проверки.
- **Повторы на стыке.** Из-за перекрытия слова на границе иногда распознаются дважды. Начало
  нового фрагмента сравнивается с концом предыдущего (до 12 слов, без учёта регистра и
  пунктуации). Текст не удаляется автоматически: появляется пометка «возможный повтор на
  стыке — сверить по аудио».
- **VAD.** Встроенный Silero VAD отделяет речь от тишины: порог 0.4, минимальная речь 150 мс,
  пауза 500 мс, запас 250 мс. Это начальные значения, а не измеренный оптимум; очень тихую
  речь VAD может пропустить — для сравнения выключите его и распознайте заново.
- **Словарь терминов** (до 800 символов): фамилии, названия проектов, аббревиатуры —
  подсказка Whisper. Лучше короткий список нужных слов: подсказка может смещать результат.
- **Пометки неуверенности.** Полный JSON Whisper даёт оценку уверенности декодера; низкая —
  реплика помечается к проверке. Это **не процент точности**: текст сохраняется как есть.
- **Качество звука.** «⋯» → «Качество звука» показывает уровень RMS и возможное отсечение
  пиков по каждому фрагменту. Это не отношение сигнал/шум; шумоподавление по умолчанию не
  применяется (его можно включить для live-записи — см. [устранение проблем](troubleshooting.md)).

## Проверка текста

Над расшифровкой — фильтр **«Проверить»**: только реплики с пометками (граница фрагмента,
низкая уверенность, возможный повтор). Выберите реплику — внизу появятся «Прослушать»
(исходная запись с запасом 2 секунды), правка текста и повторный вариант.

**Повторить сомнительные реплики** запускает второй проход Whisper только по помеченным
репликам — не больше 20 за раз, каждая с запасом ±2 секунды, той же моделью и с теми же
параметрами. Результат **не заменяет текст автоматически**: он сохраняется рядом, а
«Принять повторный вариант» подставляет его. Прежний текст хранится, «Отменить принятие»
возвращает его; ручная правка отменяет непринятый вариант. Повторный проход проверяет хеш
исходного файла и не смешивает разные версии записи. Насколько он в среднем лучше
исходного — не измерено.

Изменение расшифровки сбрасывает сводку: её нужно создать заново.

## Источники в сводке

У каждого пункта сводки одна кнопка **▶ 00:41:22 · 3** — время первой реплики и сколько
реплик подтверждают пункт. Наведение показывает текст всех исходных реплик (из сохранённой
расшифровки, с учётом ручных правок). Нажатие проигрывает их по очереди: реплики сортируются
по времени, пересекающиеся и близкие (до 5 секунд) объединяются, по краям добавляется
секунда контекста. Звук читается из исходного файла, копии не создаются. «■ Стоп», другая
запись или другой значок останавливают очередь. В Obsidian остаются обычные ссылки на
реплики с таймкодами.

Проверка ссылок гарантирует, что реплика существует, но не доказывает, что модель верно
её поняла.

## Ручная проверка на Mac

Тесты (`pytest`) покрывают конвейер с поддельными Whisper и llama-server. Перед выпуском
изменений распознавания полезен прогон с настоящими FFmpeg, Whisper.cpp и VAD:

```bash
scripts/make_smoke_fixture.sh smoke.wav 300   # синтетическая речь нужной длины через say
uv run python scripts/smoke_audio.py smoke.wav
```

`smoke_audio.py` печатает план границ фрагментов, сохраняет журналы в `./smoke-logs/` и
падает сразу, если запись слишком короткая для второго фрагмента. Синтетическая английская
речь проверяет работоспособность конвейера, а не качество распознавания русских встреч.
