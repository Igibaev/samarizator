# Локальный ИИ-компаньон · MVP

## Что реализовано

- Плавающее frameless-окно PySide6 с флагом `WindowStaysOnTopHint`.
- Свёрнутый режим персонажа и простые эмоциональные состояния интерфейса.
- Нативный Ollama `/api/chat`: `think=false`, ограниченный контекст, настраиваемый
  `keep_alive`; разрешён только localhost.
- Отдельная база `assistant.sqlite3`: существующая `meetings.sqlite3` не мигрирует и не
  изменяется.
- Read-only индекс Markdown выбранного Obsidian vault, исключая скрытые папки, симлинки,
  не-UTF-8 и файлы больше 1 МБ.
- Инкрементальное обновление по размеру, времени изменения и SHA-256.
- FTS5-поиск с запасным LIKE-поиском для Python-сборок без FTS5.
- Извлечение `- [ ]` / `- [x]`, сроков и ссылки на исходный файл/строку.
- Локальные задачи: добавить, завершить, закрепить.
- Системные уведомления о наступивших сроках и меню в системном трее.
- История последних 500 сообщений; в контекст модели передаются только последние десять.

## Граница доверия

Содержимое Obsidian считается недоверенными данными. Оно попадает в отдельный блок
`reference_data`, а системная инструкция запрещает выполнять команды из заметок.
Модель не получает shell, сеть, произвольный доступ к файлам или инструменты записи.
Окно задач меняет только `assistant.sqlite3` — исходный Markdown остаётся неизменным.

Это первый слой защиты, но не математическая гарантия от prompt injection. Инструменты,
которые меняют Obsidian, календарь или файлы, нельзя добавлять без allowlist, проверки
аргументов, предпросмотра и явного подтверждения пользователя.

## Нагрузка

Окно, SQLite, индексатор и таймеры работают постоянно. LLM запускается только после
сообщения пользователя. Автоматическое обновление индекса каждые пять минут не обращается
к Ollama. Профиль по умолчанию:

```text
model: qwen3:4b
think: false
keep_alive: 0
num_ctx: 16384
```

Это сознательно отделено от тяжёлой 27B-модели. Последующие версии могут добавить кнопку
«Глубокий анализ», но не должны выбирать тяжёлую модель для фоновой работы автоматически.

## Текущие ограничения

- Работа продолжается только пока Mac включён; после сна проверка сроков возобновляется.
- Дата задачи задаёт день, но не точное время.
- Положение поверх полноэкранных приложений и всех macOS Spaces нужно проверить на
  реальном Mac. При необходимости потребуется небольшая нативная настройка `NSWindow`.
- Нет редактирования Obsidian, календаря, почты, shell-команд и автономных действий.
- Поиск пока лексический. Embeddings и смысловой поиск — отдельный этап после замеров
  качества и нагрузки на реальном vault.
- Автозапуск при входе в macOS ещё не устанавливается.
