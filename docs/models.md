# Зависимости и модели

## Рекомендация для M4 Pro / 48 ГБ

Для максимально качественной русской транскрибации начните с полной мультиязычной
`large-v3` и профиля качества:

```bash
git switch quality-m4-dual-summaries
git pull --ff-only
./start.sh --quality --large-v3
```

Команда скачивает веса с официального хранилища конвертированных моделей whisper.cpp,
выбирает их в настройках и ставит бюджет приложения 16 ГиБ. Загрузка нужна один раз;
модель хранится в:

```text
~/Library/Application Support/Samarizator/models/ggml-large-v3.bin
```

Далее запускайте `./start.sh`. Чтобы применить новую модель к уже добавленному аудио,
нажмите **«Распознать заново»**, а не «Распознать / продолжить». Параметры продолжения
фиксируются для записи, чтобы не смешивать результаты разных моделей.

## Какую Whisper выбрать

Все варианты в таблице мультиязычные. Размеры приведены по таблице whisper.cpp;
скорость и пик памяти зависят от версии whisper.cpp, длительности фрагмента и CPU/Metal.

| Модель | Размер весов | Когда выбирать |
|---|---:|---|
| `large-v3` | 2,9 ГиБ | Первая рекомендация для максимальной точности на M4 Pro / 48 ГБ |
| `large-v3-q5_0` | 1,1 ГиБ | Меньше места и памяти; квантование может немного изменить результат |
| `large-v3-turbo` | 1,5 ГиБ | Существенно быстрее; OpenAI описывает небольшое снижение точности относительно `large-v3` |
| `large-v3-turbo-q5_0` | 547 МиБ | Самый лёгкий из этих вариантов; больше компромиссов ради скорости и памяти |

Слово `turbo` означает ускоренную архитектуру, а `q5_0` — квантованные веса. Это не
строгая лестница качества для любой записи: правильнее прогнать один эталонный файл через
две модели и сравнить ошибки в именах, числах, терминах и пропуски целых фраз.

Полная `large-v3` устанавливается автоматической командой выше. Альтернативы можно
скачать вручную, например:

```bash
mkdir -p "$HOME/Library/Application Support/Samarizator/models"
curl -L --fail --retry 5 \
  -o "$HOME/Library/Application Support/Samarizator/models/ggml-large-v3-turbo.bin" \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo.bin
```

После загрузки откройте **Настройки → Распознавание речи · локально → Модель Whisper
(.bin) → Выбрать…**, укажите файл и сохраните настройки. Удалять прежнюю модель не нужно:
для отката просто выберите старый `.bin`. Для полной `large-v3` оставьте бюджет 16 ГиБ;
проверка приложения требует, чтобы оценка `размер модели × 2,5 + 600 МиБ` занимала не
более 80% выбранного бюджета.

Актуальный список, размеры и ссылки: [whisper.cpp — Models](https://github.com/ggml-org/whisper.cpp/blob/master/models/README.md).
Описание `large-v3` и `turbo`: [OpenAI Whisper](https://github.com/openai/whisper/blob/main/README.md).

## Корпоративная модель сводок

Samarizator не скачивает LLM и не выбирает публичный запасной сервис. В настройках нужно
указать имя модели, реально доступной на корпоративном OpenAI-совместимом endpoint.
Универсального имени здесь нет: оно зависит от каталога и deployment вашей компании.

Для качественной подробной сводки выбирайте модель, которая:

- уверенно следует инструкциям на русском и не подменяет сводку пересказом;
- стабильно выдаёт структурированный JSON без обрезания;
- имеет контекст не менее 32k токенов и допускает ответ от 6k токенов;
- является полной/старшей instruction-моделью, а не вариантом `mini`, `fast` или `lite`.

Стартовые параметры: **12000 символов текста на запрос** и **6000 токенов ответа**.
Больший блок уменьшает число запросов, но не всегда улучшает полноту; конвейер всё равно
обходит всю расшифровку блоками и затем сверяет тезисы с источником. Если корпоративный
шлюз ограничивает `max_tokens`, используйте разрешённый лимит (по умолчанию в приложении
`3000`). Аудио остаётся локально, на API отправляется только текст расшифровки.

## Зависимости и происхождение весов

Python-пакеты зафиксированы с хешами в `uv.lock`; `start.sh` использует `uv sync --frozen`. FFmpeg и Whisper.cpp устанавливаются Homebrew из его актуальных формул. Веса загружаются отдельно, не включаются в Git. `download-manifest.json` фиксирует SHA-256 полученных файлов для локального учёта; это не независимая криптографическая проверка опубликованного эталона. Корпоративный проверенный файл можно разместить вручную и выбрать в настройках.

| Компонент | Назначение | Первичный источник |
|---|---|---|
| Whisper.cpp, модель small-q5_1 | Локальное распознавание речи, CPU | https://github.com/ggml-org/whisper.cpp |
| GGML Whisper models | Мультиязычные веса | https://huggingface.co/ggerganov/whisper.cpp |
| PySide6 | Десктопный интерфейс Qt | https://doc.qt.io/qtforpython-6/ |
| FFmpeg | Извлечение первой аудиодорожки | https://ffmpeg.org/ |
| Homebrew whisper-cpp | Установка CLI на Mac | https://formulae.brew.sh/formula/whisper-cpp |

Каждый сторонний компонент и набор весов имеет собственные условия лицензирования. Установка зависимостей не перелицензирует их. Для корпоративного распространения проверьте условия конкретных используемых версий, моделей, Qt/PySide6 и сборки FFmpeg. Этот репозиторий не включает и не распространяет веса моделей.
