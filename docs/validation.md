# Проверки

Актуальное состояние относится к ветке `quality-m4-dual-summaries`. GitHub Actions не
используется; проверки запускаются локально перед публикацией.

- Полный набор pytest проверяет SQLite/checkpoints, Whisper JSON, границы фрагментов,
  повторный проход, сводки, интерактивные источники, очередь аудио, Obsidian и GUI Qt.
- Ruff проверяет исходный код, тесты и скрипты; `bash -n` проверяет `start.sh`.
- `scripts/smoke_audio.py` предназначен для ручного запуска на Mac с настоящими FFmpeg,
  Whisper.cpp и аудиофайлом. Он не обращается к API суммаризации.
- HTTP-протокол корпоративной модели проверяется контролируемым MockTransport. Настоящие
  endpoint и ключ не предоставлены, поэтому качество и доступность корпоративного API
  можно подтвердить только в пользовательском окружении.
- Автоматическое определение собеседников удалено. Свежая установка больше не содержит
  `sherpa-onnx`, голосовых ONNX-моделей и отдельного этапа обработки всей записи.

Перед выпуском нужен полный пользовательский сценарий на M4 Pro: новая расшифровка,
остановка/продолжение, исправление текста, оба вида сводки, наведение и прослушивание
источников, экспорт и открытие заметки в Obsidian.
