# Проверка на живом Mac — этап 0

Компаньон пишется в облачном контейнере, где нет Swift и macOS: там код можно
проверить только тестами Python и структурной проверкой Swift. Запускался ли он
по-настоящему — знает только этот чек-лист. Займёт около часа.

Нужны: Mac с вырезом, Xcode Command Line Tools (`xcode-select --install`),
Obsidian с открытой папкой `~/Documents/Samarizator` как хранилищем.

## 1. Обновить и собрать

```bash
cd ~/путь/к/samarizator
git fetch origin && git checkout ai-companion && git pull --ff-only
./start.sh                      # обновит окружение и откроет Samarizator; окно можно оставить
```

Во втором окне терминала:

```bash
cd ~/путь/к/samarizator/focus-companion
./build-app.sh 2>&1 | tee ~/Desktop/companion-build.log
```

Если сборка упала — дальше не идите, пришлите `~/Desktop/companion-build.log`.

Если собралось, приложение откроется само. Закройте его (значок в строке меню →
«Выход») и запустите из терминала, чтобы остался лог:

```bash
./FocusCompanion.app/Contents/MacOS/FocusCompanion 2>&1 | tee ~/Desktop/companion-run.log
```

Отмечайте каждый: ✅ как описано, ❌ не так — и одной фразой, что видели.

## 2б. Живость — только после того, как сценарии 1–13 прошли

Значок в строке меню → «Живость (бета)» — галочка включает.

| # | Что сделать | Что должно быть |
|---|---|---|
| 14 | Включить «Живость (бета)» | В первый раз за день (с 5:00 до 18:00) через пару секунд — реплика под полкой: что ждёт со встреч или что было вчера |
| 15 | Не трогать мышь и клавиатуру 5 минут | Глаза превращаются в щёлочки и медленно «дышат» |
| 16 | Шевельнуть мышью | Глаза коротко распахиваются и возвращаются к обычным |
| 17 | Поработать 10 минут, изредка поглядывая на вырез | Иногда взгляд в сторону или двойное моргание — не чаще раза в полторы минуты |
| 18 | После 18:00 (если утром реплика была) | Одна вечерняя реплика только о сделанном |
| 19 | После 23:00 | Веки тяжелее, моргает реже |

Главный вопрос здесь не «работает ли», а «не раздражает ли». Если что-то
отвлекает — напишите, что именно: частоту и силу можно подкрутить.

## 3. Что прислать

- Номера сценариев с ❌ и по фразе на каждый. Скриншот, если словами не описать.
- `~/Desktop/companion-run.log` — лог запуска.
- Если что-то не так с заметками — вывод этой команды из корня репозитория:

```bash
.venv/bin/python -m samarizator.companion journal
```

Записи, расшифровки и ключи не присылайте: для починки они не нужны.
