# Модели внутри приложения

Сюда кладутся модели, которые сборка (`packaging/macos/build.sh`) встраивает в
Samarizator.app. Если модели здесь нет, сборка скачивает её; если её нет и в приложении,
приложение предложит скачать её при первом запуске.

`bundle.json` говорит, какие модели встраивать:

| Ключ | Что | Пример |
|---|---|---|
| `whisper` | распознавание речи | `ggml-large-v3-turbo.bin` |
| `vad` | выделение речи | `ggml-silero-v6.2.0.bin` |
| `llm` | модель сводок и чата, GGUF | `Qwen3-4B-Instruct-2507-Q4_K_M.gguf` |
| `files.<имя>.sha256` | контрольная сумма — сборка проверит файл | |
| `files.<имя>.url` | откуда скачать, если файла нет (для известных моделей не нужен) | |

Пустая строка — не встраивать (`"llm": ""`: модель сводок скачивается в приложении).

## Как добавить модель

Файлы моделей хранятся в Git LFS — обычный Git не принимает файлы больше 100 МБ.

```bash
git lfs install                                   # один раз на машине
cp ~/Downloads/Qwen3-4B-Instruct-2507-Q4_K_M.gguf models/
uv run python -m samarizator.model_bundle split models/Qwen3-4B-Instruct-2507-Q4_K_M.gguf
# впишите имя файла в bundle.json → "llm"
git add models && git commit -m "Модель сводок в сборке" && git push
```

`split` режет файл на части по 1,9 ГБ (`.part-000`, `.part-001`, …) — на бесплатном
тарифе GitHub один файл в LFS не может быть больше 2 ГБ — и записывает контрольную
сумму в `bundle.json`. Сборка склеит части и проверит сумму. Файлы до 1,9 ГБ (модели
Whisper, VAD) резать не нужно.

## Ограничения GitHub — прочитайте до загрузки

- **Место в LFS.** Бесплатно — 1 ГБ хранения и 1 ГБ трафика в месяц, дальше нужны
  платные пакеты (Settings → Billing → Git LFS data). Модель сводок на 2,5–19 ГБ в эти
  рамки не помещается, а каждая сборка в Actions скачивает её из LFS заново.
- **Диск сборщика.** У стандартного macOS-раннера GitHub около 14 ГБ свободного места:
  Qwen3 4B (2,5 ГБ) и Gemma 3 12B (7,3 ГБ) поместятся, Qwen3 30B-A3B (18,6 ГБ) — нет.
  Её встраивайте при сборке на своём Mac (`./packaging/macos/build.sh`).
- **Размер .dmg.** Релиз на GitHub принимает файлы до 2 ГБ, поэтому `.dmg` со
  встроенной моделью сводок забирайте из артефактов сборки, а не из Releases.

Без модели сводок в сборке `.dmg` весит около 300 МБ, а модель скачивается в приложении
один раз — с докачкой.
