# Модели

Модели в репозитории не хранятся. Модель распознавания речи (Whisper) и модель сводок
пользователь выбирает и скачивает в самом приложении при первом запуске. Для каждой
модели там видно, сколько она весит, сколько памяти (RAM) занимает во время работы и
подходит ли она этому Mac. Скачивание докачивается после обрыва, дальше всё работает
без интернета.

В приложение встраивается только `ggml-silero-v6.2.0.bin` (около 1 МБ) — модель,
которая находит в записи участки с речью. Это решает `bundle.json`:

| Ключ | Что | По умолчанию |
|---|---|---|
| `whisper` | распознавание речи | `""` — скачивается в приложении |
| `vad` | выделение речи | `ggml-silero-v6.2.0.bin` |
| `llm` | модель сводок и чата, GGUF | `""` — скачивается в приложении |
| `files.<имя>.sha256` | контрольная сумма — сборка проверит файл | |
| `files.<имя>.url` | откуда скачать (для моделей из приложения не нужен) | |

## Сборка, которой не нужен интернет

Если приложение должно работать сразу, без загрузок (например, для Mac без доступа в
сеть), впишите модель в `bundle.json`, например `"whisper": "ggml-large-v3-turbo.bin"`,
или передайте модель сводок при сборке: `SAMARIZATOR_BUNDLE_LLM=qwen3-4b`. Сборка возьмёт
файл из этой папки на машине сборки (Git его игнорирует), а если его нет — скачает.
`.dmg` станет больше на размер модели; GitHub Releases принимает файлы до 2 ГБ, поэтому
такую сборку берите из артефактов.
